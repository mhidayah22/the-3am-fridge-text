One one-line smart-fridge text, 132 characters: at 3am the fridge is the only one in the house still working, still cold, and still holding the salad its owner swore to eat on Monday. The program writes the line to `entry.txt`, honouring `MAKEFUN_OUTPUT_DIR` first, then `/output`, then a local fallback.

## Run it

```sh
python3 main.py
```
